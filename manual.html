Geditor 초보자 사용 설명서

가볍고 강력한 Geditor의 모든 기능을 맥(Mac)과 윈도우(Windows) 환경에 맞춰 쉽게 배워보세요.

🌟 1. Geditor 소개 및 화면 구성

Geditor(지에디터)는 Rust 기반의 네이티브 코어로 개발되어 실행 속도가 매우 빠르고, 시스템 자원을 적게 차지하는 현대적인 텍스트 에디터입니다. 대용량 텍스트 파일도 버벅임 없이 빠르게 열고 편집할 수 있습니다.

1. 상단 메뉴 바 (TopMenuBar)

파일, 편집, 보기, AI 도우미, 설정 등 에디터의 모든 기능을 마우스 클릭으로 간편하게 실행할 수 있습니다.

2. 좌측 탐색기 (Sidebar)

현재 열린 프로젝트의 파일 트리를 보여줍니다. 자주 쓰는 폴더를 '즐겨찾기'에 등록해 1초 만에 이동할 수 있습니다.

3. 중앙 편집 영역 (Editor)

VS Code와 동일한 강력한 Monaco Editor 엔진이 탑재되어 자동 완성, 코드 서식, 다중 커서를 완벽하게 지원합니다.

4. 하단 상태 표시줄 (StatusBar)

현재 파일의 한글 인코딩(UTF-8 / EUC-KR), 줄바꿈(LF / CRLF), 언어 모드 및 커서 위치를 실시간으로 확인하고 클릭하여 변경할 수 있습니다.

📂 2. 파일 & 탐색기 관리

파일을 생성하고 저장하거나 원하는 폴더를 열고 관리하는 방법입니다.

🍎 Mac 사용자 메뉴 & 단축키
  • 새 파일 만들기: 상단 메뉴 파일 ➔ 새 파일 또는 ⌘ Cmd + N
  • 파일 열기: 상단 메뉴 파일 ➔ 파일 열기... 또는 ⌘ Cmd + O
  • 폴더 열기: 상단 메뉴 파일 ➔ 폴더 열기... 또는 ⇧ Shift + ⌘ Cmd + O
  • 저장하기: 상단 메뉴 파일 ➔ 저장 또는 ⌘ Cmd + S
  • 탐색기 숨기기/보이기: ⌘ Cmd + B
🪟 Windows 사용자 메뉴 & 단축키
  • 새 파일 만들기: 창 상단 메뉴 파일 ➔ 새 파일 또는 Ctrl + N
  • 파일 열기: 창 상단 메뉴 파일 ➔ 파일 열기... 또는 Ctrl + O
  • 폴더 열기: 창 상단 메뉴 파일 ➔ 폴더 열기... 또는 Shift + Ctrl + O
  • 저장하기: 창 상단 메뉴 파일 ➔ 저장 또는 Ctrl + S
  • 탐색기 숨기기/보이기: Ctrl + B
💡
폴더 즐겨찾기(Favorites) 기능
좌측 탐색기 상단의 ⭐ 즐겨찾기 영역 옆의 + 버튼을 누르면 원하는 폴더를 바로 등록할 수 있습니다. 등록된 폴더를 클릭하면 전체 폴더 트리가 유지되면서 해당 위치로 즉시 스크롤 이동합니다.

🪟 3. 화면 분할 & 실시간 미리보기

한 화면에서 코드를 작성하면서 결과 화면이나 터미널을 나란히 띄워두고 작업할 수 있습니다.

  • 화면 우측 분할 (Split Panes)

    현재 열려 있는 편집 화면을 우측으로 반분할하여 두 파일을 동시에 비교하며 편집할 수 있습니다.
    🍎 Mac ⌘ Cmd + \  |  🪟 Windows Ctrl + \

  • 마크다운 실시간 나란히 보기 (Dual View)

    마크다운(.md) 문서를 작성할 때 우측에 예쁘게 렌더링된 결과를 실시간으로 확인합니다.
    🍎 Mac ⇧ Shift + ⌘ Cmd + V  |  🪟 Windows Shift + Ctrl + V

  • 웹 페이지 HTML 미리보기 & 기본 브라우저 열기

    .html 파일을 열면 상단에 [웹페이지 렌더링] 탭이 생성되어 브라우저처럼 디자인을 바로 볼 수 있습니다. 또한 상단의 [브라우저로 열기] 버튼을 누르면 내 컴퓨터의 기본 브라우저(Safari, Chrome, Edge)에서 즉시 열립니다.

  • 내장 네이티브 터미널 (Terminal) 열기

    별도의 터미널 프로그램을 실행하지 않아도 에디터 하단에 즉시 네이티브 셸이 열립니다.
    🍎 Mac macOS zsh 터미널 (⌘ Cmd + T)
    🪟 Windows 윈도우 cmd.exe / PowerShell 터미널 (Ctrl + T)

🤖 4. 스마트 인공지능(AI) 도우미 200% 활용법

회사나 보안 환경에서 유료 API 키가 없어도 걱정 없습니다! Geditor는 별도의 API 발급 없이 브라우저 웹 로그인(Google Gemini, ChatGPT, Claude) 방식을 지원하여 자유롭게 질문하고 코드를 자동으로 붙여넣을 수 있습니다.

1. 프로그램 내 AI 사이드 패널 내장

별도 창으로 팝업되지 않고 에디터 우측 사이드 패널에서 바로 열려 작업 흐름을 방해하지 않습니다. 드래그하여 패널 너비를 자유롭게 조절할 수 있습니다.
🍎 Mac ⇧ Shift + ⌘ Cmd + A
🪟 Windows Shift + Ctrl + A

2. 선택 영역으로 AI 질문 자동 입력

에디터에서 코드나 텍스트를 마우스로 드래그한 후 단축키를 누르면 AI 사이드 패널이 열리며 질문 프롬프트 창에 코드가 자동 입력됩니다.
🍎 Mac ⌥ Option + A
🪟 Windows Alt + A

3. [선택영역 본문붙혀넣기] 표 및 마크다운 완벽 보존 삽입

AI 답변 내용 중 필요한 텍스트, 표(Table), 코드 블록 등을 마우스로 드래그하여 선택한 후 패널 상단의 [선택영역 본문붙혀넣기] 버튼을 누르면 현재 에디터 문서의 커서 위치에 즉시 삽입됩니다.
렌더링된 웹 화면의 표와 서식을 GitHub Flavored Markdown(GFM) 표 및 마크업 서식으로 자동 변환하여 삽입하므로 마크다운 문서에 깔끔한 표 형태로 입력됩니다.

4. 사내 엔터프라이즈 AI 접속 주소 설정

환경설정(⌘, / Ctrl+,) ➔ AI 도우미 주소에서 사내 프라이빗 AI 포털 주소를 지정하여 사내 AI 서비스를 패널에서 바로 사용할 수 있습니다.

🔒
안전한 기업용 SSO 웹 세션 유지
Geditor의 AI 도우미 창은 OS 네이티브 독립 웹뷰(macOS: WKWebView, Windows: WebView2)를 사용하여 구글, 마이크로소프트 회사 계정 로그인이 안전하게 보관되므로 매번 로그인할 필요가 없습니다.

🔤 5. 한글 깨짐(인코딩) 및 줄바꿈 해결

오래된 메모장 파일이나 관공서 문서, 전산 시스템 텍스트를 열었을 때 한글이 처럼 깨져 보이나요? Geditor에서는 단 한 번의 클릭으로 해결됩니다.

한글 인코딩 변환 (UTF-8 ↔ EUC-KR)

화면 우측 하단 상태 표시줄의 [UTF-8] 또는 [EUC-KR] 글자를 마우스로 클릭하면 즉시 인코딩이 상호 전환되면서 깨졌던 한글이 정상적으로 나타납니다.

줄바꿈 형식 변환 (LF ↔ CRLF)

맥/리눅스 표준 줄바꿈(LF)과 윈도우 표준 줄바꿈(CRLF)을 하단 상태 표시줄의 글자를 클릭하여 손쉽게 변환할 수 있습니다. 협업 시 줄바꿈 충돌을 예방합니다.

🛡️ 7. 작업 보호 & 안전 종료

열심히 작성하던 내용을 저장하지 않은 상태에서 실수로 창을 닫아버려도 걱정하지 마세요! Geditor가 소중한 데이터를 안전하게 지켜줍니다.

⚠️
미저장 변경사항 보호 시스템
파일 내용이 수정된 상태(파일명 옆에 하늘색 동그라미 ● 표시)에서 프로그램을 종료하려 하면, 창이 바로 닫히지 않고 확인 모달 대화상자가 나타납니다.
🍎 Mac 종료 방법
  • 창 좌측 상단 빨간색 닫기 버튼 (●) 클릭
  • 키보드 단축키 ⌘ Cmd + Q
  • 상단 메뉴 Geditor ➔ Geditor 종료
🪟 Windows 종료 방법
  • 창 우측 상단 닫기 버튼 (✕) 클릭
  • 키보드 단축키 Alt + F4 또는 Ctrl + Q
  • 창 상단 메뉴 파일 ➔ Geditor 종료

미저장 경고 모달에서의 3가지 선택지:

  • 모두 저장 후 종료 (Enter): 수정된 모든 파일을 디스크에 안전하게 저장한 뒤 프로그램을 닫습니다. (새 문서인 경우 저장 위치를 물어봅니다.)
  • 저장하지 않고 종료: 최근 변경 사항을 저장하지 않고 즉시 닫습니다.
  • 취소 (Esc): 종료를 취소하고 현재 편집 화면으로 그대로 돌아옵니다.
